# public/images/guebbit-logotype.svg

## Purpose

The horizontal "long" logotype for the guebbit brand, rendered entirely as vector paths. It is the scalable text-plus-mark lockup used where an SVG is needed (e.g. favicons, inline UI, print), complementing the raster PNG for contexts that require a fixed-pixel or colored variant.

## Key elements

- **`<svg id="guebbit-logo-long">`** — root element; `viewBox="0 0 577.347 175.894"` defines the horizontal lockup aspect ratio.
- **`<desc>` with `xmlns:guebbit`** — carries brand metadata (title, description, emphasis) under a custom namespace for semantic/SEO purposes.
- **`<!-- G scuro -->` path** — the decorative "G" logo mark (single compound path, ~200 pt tall).
- **`<g> uebbit scuro`** — dark-variant wordmark: individual `<path>` elements for U, E, B₁, B₂, I, T.
- **`<g> uebbit chiaro`** — light-variant wordmark: same letter set (G, U, B₁, B₂, I, T) offset ~5 px lower, intended for use on dark backgrounds.

## Relationships

- **`public/images/guebbit-logo-colored.png`** — raster, full-color counterpart of the same brand identity. The SVG here is the monochrome/vector logotype; the PNG is the colored bitmap version used where vector rendering or transparency isn't needed.

## Notes

- All letterforms are hand-drawn `<path>` data, **not** `<text>` elements — you cannot change the text by editing a string; any wording change requires regenerating from the Illustrator source.
- Generated by **Adobe Illustrator 16.0.0** (SVG Export Plug-In, SVG 1.1). Re-exporting may shift path precision or strip the custom `guebbit` namespace in `<desc>`.
- The two text groups ("scuro" / "chiaro") overlap in the same coordinate space with a slight vertical offset; they are meant to be shown one-or-the-other, not both simultaneously.
- The file is referenced as a static asset under `/public/images/`; no build-step transforms it.
