# src/app/router/index.ts

## Purpose

The application's single Vue Router instance. It wires locale-prefixed routes, merges all domain routes contributed by enabled modules via the kernel registry (naming no domain itself), and registers the global guards that restore auth, enforce access, sync the i18n locale, and manage post-navigation concerns (tab title, a11y announcement, focus).

## Key elements

- **`moduleRoutes`** — Result of `collectModuleRoutes(enabledModules)`. The sole entry point through which every domain route enters the app; this file never names a domain.
- **`router`** — The `createRouter` instance using `createWebHistory`. Owns `scrollBehavior`, the route table, and all global guard registrations.
- **Route table** — Top-level `/` and `/oauth/callback` redirects (locale-less entry points), then a `/:locale` parent with children: `Home`, four static shop pages (`about`, `faq`, `terms`, `privacy`), an `Error` route, the spread `...moduleRoutes`, and a locale-scoped catch-all 404. A second top-level catch-all handles URLs with no locale segment.
- **`scrollBehavior`** — Restores saved position on back/forward, scrolls to hash anchors, preserves position on query-only changes, and scrolls to top otherwise. Uses `smooth` unless `prefers-reduced-motion` is active (WCAG 2.3.3).
- **`router.onError`** — Global navigation-error handler. Reports to the observability store, then redirects: 401 → sign-in page (preserving the intended `to.fullPath`); 403 → Error with a dedicated message; other client errors → Error with their status; 5xx/unknown → Error 500.
- **`router.beforeEach`** — Calls `tryRestoreAuth()` (silently restores token + profile) then `enforceRouteAccess(to)`. Order is load-bearing: the profile must exist before the access check runs.
- **`router.beforeResolve(localeChoice)`** — Registered after `beforeEach` so a blocked navigation never triggers a dictionary load. Loads/switches the active i18n locale for the target route.
- **`router.afterEach`** (truncated in source) — Sets the browser tab title (via `translate` + `appName`), fires an a11y announcement, and moves focus to `<v-main>` on real page changes while respecting anchors and query-only navigations (WCAG 2.4.2 / 2.4.3).
- **`readLocaleParameter`** — Safely extracts the `:locale` param (guards against `string[]` from repeated params).
- **`prefersReducedMotion`** — Reads `matchMedia('(prefers-reduced-motion: reduce)')` on each call so the OS setting can change without a reload.

## Relationships

No graph neighbors are listed in the dependency graph. The file's direct imports span guards (`locale-choice`, `authentications`), i18n, navigation helpers, the a11y announcer, the observability store, the kernel registry, and the module list (`@/modules`). Inter-module coupling is enforced externally by `eslint.config.ts`'s generated `moduleCouplingRules`, not by this file.

## Notes

- **Adding a domain:** toggle it in `src/modules.ts` and its folder; nothing in this file changes. Forgetting a coupling rule surfaces as a lint error, not a runtime bug.
- **`appName`** comes from `VITE_APP_NAME`; a derived project renames the tab suffix without editing this file.
- **Guard order is intentional and load-bearing:** `beforeEach` (auth → access) → `beforeResolve` (locale) → `afterEach` (title/focus). Reordering any of these breaks the stated invariants (e.g., a blocked visitor paying for a dictionary load, or `translate` reading a stale locale).
- **`onError` uses `to`, not `router.currentRoute`:** the navigation aborted before commit, so `currentRoute` still points at the page being *left*. Using it here would have sent users back to where they already were after a failed login redirect.
- **Static pages** (`about`, `faq`, `terms`, `privacy`) live here rather than in a module because they describe the shop itself, not a domain. Their names are generated by `staticPageRouteName` to keep them in the shared naming scheme.
