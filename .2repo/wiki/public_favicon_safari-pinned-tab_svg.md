# public/favicon/safari-pinned-tab.svg

## Purpose

A black-and-white vector icon used as the **Safari pinned-tab** favicon. When a user pins this site in Safari, this SVG replaces the default globe in the tab bar. It is a potrace-traced version of the project logo, rendered as a single filled path.

## Key elements

- **`<path>` (single, fill `#000000`)** — The entire icon is one complex Bezier path describing the logo shape. There are no strokes, gradients, or additional elements.
- **`<g>` transform `scale(0.1, -0.1)`** — Standard potrace output: scales the internal coordinate space (0–558) and flips the Y-axis so the path renders upright.
- **`<metadata>`** — States the file was generated by potrace 1.14; it is not rendered by any browser.
- **`viewBox="0 0 558 558"` / `width`/`height` 558 pt** — Square canvas; Safari scales it down to the tab-bar icon size.

## Relationships

- **`public/images/guebbit-logo.svg`** — Almost certainly the source artwork that was traced (via potrace) to produce this file. The shape in this file is a single-color silhouette of that logo.
- **`public/favicon/favicon-16x16.png`, `favicon-32x32.png`, `mstile-150x150.png`** — Sibling favicon assets. This SVG is the vector/pinned-tab variant while the PNGs serve raster favicon requests and the mstile file serves legacy Windows/IE tiles. All four are typically referenced together in the HTML `<head>`.

## Notes

- The file is **monochrome** (pure black on transparent). Safari renders the pinned-tab icon on a white or dark background, so a single-color path is the expected convention—do not add color fills.
- Because it was generated by **potrace**, the path data is not hand-authored. Regenerate it from the source logo rather than editing the `d` attribute directly.
- No `id`, `class`, or `aria-*` attributes exist; it is purely a static shape with no interactive or accessibility hooks.
