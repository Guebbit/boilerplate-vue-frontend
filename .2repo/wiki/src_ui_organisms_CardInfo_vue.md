# src/ui/organisms/CardInfo.vue

## Purpose

An organism-level Vue component that renders a Vuetify `v-card` containing a gradient icon tile, a title, and a description. It exists as a reusable building block for "info card" layouts where the accent color is driven by the app's theme.

## Key elements

- **Props** (`title`, `description`, `variant?`) — `title` and `description` are required strings; `variant` is an optional `ThemeAccent` that selects the tile gradient (defaults to `'primary'`).
- **`variantClass` (computed)** — The only reactive logic in the file. Maps the `variant` prop to a set of Tailwind gradient utility classes (`bg-gradient-to-br from-… to-[rgb(var(--v-theme-…-darken-1))] text-on-…`). Falls back to `primary` when `variant` is undefined.
- **`icon` slot** — Named slot that replaces the default `Info` icon (lucide-vue-next, size 28) inside the gradient tile.
- **Template layout** — A `v-card` with a CSS-grid two-column layout (`84px 1fr`): left column is a 84×84 rounded-2xl tile (`aria-hidden="true"`), right column holds the `<h3>` title and a muted `<p>` description.

## Notes

- The gradient's second stop references Vuetify theme CSS variables (`--v-theme-*-darken-1`). These variables must be generated by Vuetify's theme `variations` config; without that config the `to-[…]` color will be invalid and the gradient will fall back to a solid color.
- The component is purely presentational — no emits, no events, no data fetching. All interactivity (if any) is delegated to the consumer via the `icon` slot.
- `variant` is typed as `ThemeAccent` (imported from `@/ui/types.ts`). Adding a new accent to that union type requires a matching entry in the `variantClass` map, otherwise the tile will render with `undefined` classes.
