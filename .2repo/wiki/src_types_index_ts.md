# src/types/index.ts

## Purpose

Barrel module that aggregates all of this app's type definitions behind a single import path (`@/types`), so consumers never need to import from individual sub-modules.

## Key elements

- `export * from './api'` — re-exports API request/response types.
- `export * from './http'` — re-exports HTTP-related types (headers, status, etc.).
- `export * from './asyncapi.generated'` — re-exports types generated from the AsyncAPI spec.
- `export * from './realtime'` — re-exports realtime/subscription channel types.

## Relationships

- **src/types/api.ts** — re-exported in full.
- **src/types/http.ts** — re-exported in full.
- **src/types/asyncapi.generated.ts** — re-exported in full; generated by `npm run gen:asyncapi` from `asyncapi.yaml`.
- **src/types/realtime.ts** — re-exported in full.

This file is a pure pass-through; it adds no logic, augmentation, or filtering.

## Notes

- `asyncapi.generated.ts` is a **generated** file. Do not edit it by hand. Regenerate with `npm run gen:asyncapi` after changing `asyncapi.yaml`.
- This repo's AsyncAPI copy is a **subset** of the backend's full contract (the same generator runs on both sides with different inputs). Queue-channel types are intentionally absent here; they live in the backend repo.
