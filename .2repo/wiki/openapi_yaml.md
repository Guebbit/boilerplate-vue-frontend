# openapi.yaml

## Purpose

The bundled, codegen-oriented OpenAPI 3.0.3 contract for the Ecommerce Demo API (v2.0.0). It is generated by `npm run contracts:bundle` from `shared/contracts/openapi.root.yaml` and per-module `src/modules/*/openapi.yaml` files, and is the single source of truth for client/server stubs, DTOs, and SDK generation across projects and languages.

## Key elements

- **`info`** — API title, version, and a detailed description covering the `Accept-Language` i18n contract (q-weights, `Content-Language`, `Vary`, fallback behavior, `GET /locales`).
- **`servers`** — Local (`http://localhost:3000`) and Production (`https://api.example.com`) targets.
- **`tags`** — 13 groups: Auth, Account, Users, Products, Cart, Wishlist, Orders, Payments, Delivery, Inventory, Feedback, System, Observability.
- **`paths`** — Endpoint definitions. Visible in this excerpt:
  - `GET /` — public health/ping.
  - `GET /locales` — supported languages with per-tenant capability (`backend` vs `frontend`).
  - `POST /locales` — register a new language (admin).
  - `GET /locales/tenants` — list configured translation keyspaces.
  - `GET /locales/{locale}` — the API's own deployed dictionary (tier 1).
  - `PUT /locales/{locale}` — edit language metadata (admin).
  - `DELETE /locales/{locale}` — remove language + all its entries (admin; 409 if still active).
  - `GET /locales/{locale}/messages` — dynamic frontend-tenant dictionary (overrides, not a full dict).
  - `GET /locales/{locale}/entries` — paginated, searchable list of translation rows (admin).
  - *(content truncated — additional paths for all other tags exist below.)*
- **`components`** — Shared schemas (`*Envelope`, `CreateLocaleRequest`, `UpdateLocaleRequest`, `LanguageEnvelope`, etc.), responses (`InternalError`, `Unauthorized`, `Forbidden`, `Conflict`, `ValidationError`, `NotFound`, `Success`), and parameters (`LocalePathParam`, `MessagesTenantQueryParam`, `PageParam`, `PageSizeParam`, `TextParam`, `EntryTenantQueryParam`).

## Relationships

- **`src/modules.ts`** — The module registry that this file's sources (`src/modules/*/openapi.yaml`) belong to. Changes to the module set affect what gets bundled.
- **`asyncapi.yaml`** — Complementary contract for the async/event side of the API (e.g., notifications, webhooks). Together they form the full API surface.
- **`README.md`** — Project overview; points developers to this file as the canonical API contract.
- **`CLAUDE.md`** — AI-assistant instructions; references this file as the source of API shape for code generation tasks.
- **`CHANGELOG.md`** — Records contract-breaking or additive changes to the endpoints/schemas defined here.

## Notes

- **Generated file — do not edit directly.** Make changes in the source files (`shared/contracts/openapi.root.yaml`, `src/modules/*/openapi.yaml`) and re-run `npm run contracts:bundle`.
- **`Accept-Language` is intentionally absent from per-operation parameters.** It applies globally to all 33+ endpoints. The paragraph in `info.description` is its normative contract. Declaring it per-operation would add a redundant argument to every generated function.
- **Two-tier i18n model.** `GET /locales/{locale}` serves the API's own deployed dictionary (tier 1, read-only, for client fallback). `GET /locales/{locale}/messages` serves the dynamic, editable frontend-tenant dictionary (tier 2, overrides). They are different keyspaces — the backend tenant is refused with 404 on the `/messages` route.
- **Delete-locale guard.** `DELETE /locales/{locale}` returns 409 if the language is still `active`. Deactivate first, then delete — deliberate two-step to prevent accidental loss of translation work.
- **Inactive languages are invisible to all public routes** but appear in `GET /locales` only to admin callers.
