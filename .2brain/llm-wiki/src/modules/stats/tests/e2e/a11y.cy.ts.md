# src/modules/stats/tests/e2e/a11y.cy.ts

## Purpose

Co-located accessibility (a11y) E2E test for the stats module. It declares the list of routes that belong to this module and delegates the actual sweep logic to a shared helper. By living inside the module's own directory, deleting the module automatically removes its a11y coverage.

## Key elements

- **`sweepA11y` call** — Single invocation that registers the stats module's routes under the `'admin'` role:
  - `['sales dashboard', '/en/sales/stats']`
  - `['product sales', '/en/sales/stats/products/demo-product']`
- No exports; this is a side-effect-only test file (Cypress spec).

## Relationships

- **`tests/support/e2e/a11y-sweep.ts`** — Provides the `sweepA11y` function. This file is the *caller* (route-list provider); the sweep file is the *implementation* of the actual accessibility assertions and route iteration.

## Notes

- The file is intentionally a thin route list. If the stats module adds or renames routes, the entries here must be updated in lockstep; there is no auto-discovery.
- The `'admin'` argument indicates these routes require an authenticated admin session; the sweep helper handles setup.
- Because the file is co-located under `src/modules/stats/tests/e2e/`, tooling that globs a module directory for specs (or deletes it) will pick up/remove this file without any central registry.
