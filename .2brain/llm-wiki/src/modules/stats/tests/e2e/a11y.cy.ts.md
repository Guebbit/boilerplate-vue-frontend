# src/modules/stats/tests/e2e/a11y.cy.ts

## Purpose

Declares the accessibility route list for the **stats** module and hands it to the shared a11y sweep runner. It is co-located inside the module so that removing the module automatically removes its a11y coverage with no dangling test files.

## Key elements

- **`PHONE`** — `const` tuple `[390, 844]` representing an iPhone 14-class portrait viewport; used to ensure dashboard tables still fit at mobile width.
- **`sweepA11y(...)` call** — the sole runtime statement. Registers three routes under the `'stats'` module name and the `'admin'` permission tier:
  - *sales dashboard* → `/en/sales/stats`
  - *sales dashboard, phone viewport* → same route, overridden with the `PHONE` viewport
  - *product sales* → `/en/sales/stats/products/demo-product`

## Relationships

- **`tests/support/e2e/a11y-sweep.ts`** — provides the `sweepA11y` function that this file imports and calls. The sweep file owns the actual axe-core / Playwright (or equivalent) automation; this file only supplies the module name, route list, and permission tier.

## Notes

- The file has no `describe`/`it` blocks of its own — all test generation is delegated to `sweepA11y`. Adding a new stats route that needs a11y coverage means adding one entry to the array here.
- The viewport override uses a `{ name, route, viewport }` object shape rather than the simple `[name, route]` tuple, so new mobile-viewport entries should follow that object form.
- The `'admin'` string is the permission/role tier passed to the sweep; changing it affects which auth context the sweep uses for the entire stats module, not just one route.
