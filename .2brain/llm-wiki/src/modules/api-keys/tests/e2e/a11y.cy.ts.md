# src/modules/api-keys/tests/e2e/a11y.cy.ts

## Purpose

Declares the accessibility sweep routes for the api-keys module, registering five page states (empty list, populated list, create form, create form with validation errors, create form with the one-time-secret modal) through the shared `sweepA11y` helper. Co-located with the module so that removing the module also removes its a11y coverage, and so the cross-cutting coverage spec cannot silently lose a domain.

## Key elements

- **`apiKeysListWithRow`** (local function) — Calls `cy.mintApiKey()` then navigates to `/en/api-keys`, producing the row-rendering state the bare route never reaches.
- **`sweepA11y('api-keys', […], 'admin')`** (module side-effect) — Registers five sweep entries:
  - `list, empty` — bare `/en/api-keys`
  - `list, with a credential` — uses `apiKeysListWithRow`
  - `create` — bare `/en/api-keys/create`
  - `create, submitted empty` — `prepare` clicks submit on an empty form and asserts `.v-messages__message` is visible
  - `create, secret revealed` — `prepare` fills name/permissions/expiration, submits, and asserts `[data-test=secret-reveal]` is visible

## Relationships

- **`tests/support/e2e/a11y-sweep.ts`** — Source of the `sweepA11y` helper that this file imports and invokes; that helper performs the actual axe-core / audit runs against each registered route.

## Notes

- Runs exclusively as the **admin** role, the only preset role holding `apikeys.*` permissions.
- There is no detail or edit page for a credential (fields are fixed at mint time), so the only non-trivial state beyond the two bare routes is "list with an existing row."
- `cy.mintApiKey()` is used to seed a row rather than a demo fixture, keeping the sweep self-contained.
- The "submitted empty" entry deliberately verifies `aria-describedby` association and screen-reader announcement of validation errors, not just visual colour changes.
- The "secret revealed" entry verifies the one-time-secret modal is named by its title (WCAG 4.1.2).
