# src/modules/stock-alerts/tests/e2e/a11y.cy.ts

## Purpose

Co-located accessibility test for the stock-alerts module. It declares which routes the module exposes and hands them to the shared a11y sweep utility. Co-locating the route list here (rather than in a central file) ensures that deleting the module automatically removes its a11y coverage, and a cross-cutting spec asserts no module is missing one.

## Key elements

- **`sweepA11y('stock-alerts', [['stock-alerts', '/en/stock-alerts']], 'user')`** — the sole call in the file. Registers the module name, a single route (`/en/stock-alerts`), and the required role (`'user'`) with the shared sweep helper.

## Relationships

- **`tests/support/e2e/a11y-sweep.ts`** — provides the `sweepA11y` function that this file imports and calls. This file is purely the per-module route list; all sweep logic lives in that shared helper.

## Notes

- The file is intentionally minimal: it is the route declaration, not the test logic. Adding a new routed page under stock-alerts means adding another `[label, path]` pair to the array here.
- A cross-cutting spec (`tests/cross-cutting/a11y-coverage.spec.ts`, referenced in the header comment) enforces that every routed module ships a file like this one, preventing silent loss of a11y coverage.
