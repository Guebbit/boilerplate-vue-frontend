# src/modules/returns/tests/e2e/a11y.cy.ts

## Purpose

Declares the accessibility-sweep route list for the returns module and hands it to the shared `sweepA11y` helper. It ensures the returns list, sales-returns page, and a single seeded return detail page are all audited under the signed-in admin role. The file is co-located with the module so that removing the module automatically removes its a11y coverage.

## Key elements

- **`returnDetail`** — Async helper that calls `cy.subjectId('return.requested')` to obtain a real seeded return ID, then returns the detail URL `/en/returns/{id}`. Using a real record guarantees the audit hits a populated page (with fields and decision controls) rather than a not-found view.
- **`sweepA11y('returns — admin', routes, 'admin')`** — Registers the module's sweep under the admin role with three routes:
  - `['returns list', '/en/returns']` (static)
  - `['sales returns', '/en/sales/returns']` (static)
  - `['return detail', returnDetail]` (dynamic, resolved at run time)

## Relationships

- **`tests/support/e2e/a11y-sweep.ts`** — Exports `sweepA11y`, the shared helper this file imports and calls to actually execute the axe (or equivalent) audit across the listed routes.

## Notes

- The detail route is a **function**, not a string: `sweepA11y` must support deferred URL resolution so the ID is fetched within the test context.
- A cross-cutting spec (`tests/cross-cutting/a11y-coverage.spec.ts`) asserts that every routed module has a co-located `a11y.cy.ts` like this one; deleting or moving this file without updating that assertion will break the coverage guard.
- Only the **admin** role is swept here. If the returns module has distinct customer-facing pages, they are covered elsewhere (not in this file).
