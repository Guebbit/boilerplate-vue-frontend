# src/modules/returns/tests/e2e/a11y.cy.ts

## Purpose

Registers the accessibility-audit routes for the returns module with the shared `sweepA11y` helper. It sweeps the returns list and one seeded return detail page under the **admin** (signed-in) role, ensuring both pages are checked for a11y issues as part of the e2e suite.

## Key elements

- **`returnDetail()`** — resolves the detail URL of a seeded, unanswered return via `cy.subjectId('return.requested')`, producing `/en/returns/<id>`. Uses a real record so the audit sees the actual page (fields, staff decision controls) rather than a not-found fallback.
- **`sweepA11y('returns — admin', …, 'admin')`** — the single call that registers two routes (`/en/returns` list and the resolved detail page) under the admin role for the shared a11y sweep.

## Relationships

- **`tests/support/e2e/a11y-sweep.ts`** — provides the `sweepA11y` helper; this file only supplies the route list and role, while the helper performs the actual page visits and accessibility assertions.

## Notes

- The file is deliberately co-located in `src/modules/returns/` so that deleting the module removes its a11y coverage automatically.
- `tests/cross-cutting/a11y-coverage.spec.ts` (cross-cutting spec) asserts that every routed module ships one of these files; a missing file there would be a CI failure.
- Only one return detail route is swept (reached from the list); additional return states are not enumerated here.
