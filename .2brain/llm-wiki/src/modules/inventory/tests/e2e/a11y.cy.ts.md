# src/modules/inventory/tests/e2e/a11y.cy.ts

## Purpose

Defines the list of inventory-module routes that must pass the shared accessibility sweep. It exists co-located with the inventory module so that removing the module automatically removes its a11y coverage, preventing a central list from referencing routes the app no longer serves.

## Key elements

- **`sweepA11y` call** — the sole statement in the file. Passes the module name `'inventory'`, an array of three `[label, path]` pairs, and the role `'admin'` to the shared sweep utility.
- **Route list** — three entries:
  - `['inventory ledger', '/en/inventory']`
  - `['preorders board, products', '/en/sales/preorders']`
  - `['preorders board, fulfillment orders', '/en/sales/preorders?tab=orders']`

## Relationships

- **`tests/support/e2e/a11y-sweep.ts`** — provides the `sweepA11y` function that this file imports and calls. That file contains the actual accessibility-sweeping logic; this file is purely the route declaration.

## Notes

- Two of the three routes live under `/en/sales/` rather than `/en/inventory/`; they are included because they are inventory-domain routes (preorders board), even though the URL path belongs to a different module segment.
- The file is intentionally *not* a central registry — the co-location is a deliberate architectural choice to couple a11y coverage lifetime to module lifetime.
- The `?tab=orders` query parameter distinguishes the fulfillment-orders view from the products view of the same preorders board.
