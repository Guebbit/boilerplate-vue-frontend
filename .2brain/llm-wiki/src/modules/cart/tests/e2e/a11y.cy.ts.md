# src/modules/cart/tests/e2e/a11y.cy.ts

## Purpose

Declares the set of cart-module routes that must pass the shared accessibility sweep. It exists as a thin, co-located route list so that removing the cart module automatically removes its a11y coverage—avoiding stale route entries in a central file.

## Key elements

- **`sweepA11y('cart', [['cart', '/en/cart']], 'user')`** — Registers the cart module's route (`/en/cart`, label "cart") under the `user` role for the a11y sweep. No local functions or exports; the file is a single call.

## Relationships

- **`tests/support/e2e/a11y-sweep.ts`** — Provides the `sweepA11y` helper that actually runs the axe-core (or equivalent) audit across the declared routes. This file is purely the route-list input to that helper.

## Notes

- The file is intentionally *not* imported by anything else; it is picked up by the Cypress e2e runner as a test spec.
- A cross-cutting spec (`tests/cross-cutting/a11y-coverage.spec.ts`, referenced in the header comment) enforces that every routed module has a file like this, so the pattern cannot be silently dropped.
- The relative import path (`../../../../../tests/support/…`) is five levels deep because the file sits under `src/modules/cart/tests/e2e/`.
