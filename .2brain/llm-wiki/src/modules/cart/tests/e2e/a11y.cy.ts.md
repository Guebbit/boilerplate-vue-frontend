# src/modules/cart/tests/e2e/a11y.cy.ts

## Purpose

End-to-end accessibility sweep for the cart module's single route (`/en/cart`). It exists co-located with the cart module so that deleting the module automatically removes its a11y coverage, and so that `tests/cross-cutting/a11y-coverage.spec.ts` can assert every routed module contributes one of these files.

## Key elements

- **`sweepA11y('cart', [['cart', '/en/cart']], 'user')`** — Runs the a11y sweep against the signed-in cart screen.
- **`sweepA11y('cart — guest', …)`** — Runs the a11y sweep against the guest cart in two states: empty, and with a single seeded line item (quantity 2 of `product.inStock`).
- **`prepare` callback** (guest cart-with-line case) — Writes a `guest-cart` entry into `localStorage`, reloads the page, and asserts the seeded item renders via `[data-test=guest-cart-item]`.

## Relationships

- **Imports `sweepA11y`** from `tests/support/e2e/a11y-sweep.ts` — all sweeping logic (axe-runner invocation, report formatting) lives there; this file only supplies the route list and any per-state preparation.

## Notes

- The cart has **one route, two personas** (signed-in vs. guest), so `sweepA11y` is called twice with the same URL but different user contexts and setup.
- The guest cart is purely browser-side (`localStorage`); there is no server session. The `prepare` step must run *before* the page load it validates against.
- Co-location is intentional and enforced: do not extract these calls into a central a11y list without updating the cross-cutting coverage spec.
