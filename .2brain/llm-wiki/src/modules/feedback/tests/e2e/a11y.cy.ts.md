# src/modules/feedback/tests/e2e/a11y.cy.ts

## Purpose

Cypress a11y sweep route list for the feedback module. It hands the module's routable pages to the shared `sweepA11y` helper so accessibility checks run against both the public and admin surfaces. The file is co-located with the module so that deleting the module automatically removes its a11y coverage.

## Key elements

- **`sweepA11y('feedback — public', [['contact', '/en/contact']])`** — Registers the public contact route for the a11y sweep (no surface argument → public).
- **`sweepA11y('feedback — admin', [['feedback inbox', '/en/feedback']], 'admin')`** — Registers the admin feedback-inbox route; the `'admin'` string selects the admin auth context for the sweep.

## Relationships

- **`tests/support/e2e/a11y-sweep.ts`** — Provides the `sweepA11y` helper that this file calls twice. That helper drives the actual accessibility assertions across the supplied route list.
- **`tests/cross-cutting/a11y-coverage.spec.ts`** (referenced in the module doc comment) — A cross-cutting spec that asserts every routed module has a co-located `a11y.cy.ts` like this one, preventing silent loss of a domain's a11y coverage.

## Notes

- Co-location is deliberate: a central route list would outlive the module and keep naming routes the app no longer serves.
- Each `sweepA11y` call is a one-liner registering a `[label, path]` pair; the array can grow as the module gains routes.
- The optional third argument (`'admin'`) is the only way to target the admin surface; omitting it targets the public surface.
