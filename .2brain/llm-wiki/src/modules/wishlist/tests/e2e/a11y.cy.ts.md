# src/modules/wishlist/tests/e2e/a11y.cy.ts

## Purpose

Co-located accessibility smoke test for the wishlist module's routes. It declares the wishlist's routable paths so the shared a11y sweep can audit them, keeping coverage tied to the module's lifecycle (deleting the module removes its a11y test automatically). A cross-cutting spec (`tests/cross-cutting/a11y-coverage.spec.ts`) asserts every routed module ships one of these files.

## Key elements

- **`sweepA11y` call** — the single statement in the file. Invoked with:
  - `'wishlist'` — the module name (used for reporting/identification).
  - `[['wishlist', '/en/wishlist']]` — the route list the sweep will visit.
  - `'user'` — the authenticated role under which the sweep runs.

No functions, classes, or exports are defined here; the file is purely a route declaration.

## Relationships

- **`tests/support/e2e/a11y-sweep.ts`** — exports `sweepA11y`, the generic sweep implementation that visits each listed route and runs accessibility checks. This file is a thin caller that supplies the wishlist-specific route list and role.

## Notes

- The file intentionally defines no test cases itself; all sweep logic (page load, assertion runner, reporting) lives in `a11y-sweep.ts`. Adding a new wishlist route means appending to the array here.
- Co-location is a deliberate convention: a central a11y route list would go stale when a module is removed, so the split is enforced by the cross-cutting coverage spec.
