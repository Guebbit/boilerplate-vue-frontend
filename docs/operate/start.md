# Operate

Configure the built app, watch it, and read what its users do.

| You want to                              | Start at                                  |
| ---------------------------------------- | ----------------------------------------- |
| Set a value for a deployment             | [Environment Variables](./environment.md) |
| See errors and performance in production | [Observability](./observability.md)       |
| Read the analytics and the consent rules | [Umami](./umami.md)                       |
| Watch the backend's health from the app  | [Admin Dashboard](./admin-dashboard.md)   |

Running the paired backend in production is covered by the
[backend's Operate section](https://github.com/Guebbit/boilerplate-node-backend/blob/main/docs/operate/start.md),
for anyone who also runs it.
